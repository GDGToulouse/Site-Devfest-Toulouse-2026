## 2016 — https://2016.devfesttoulouse.fr/

**Stack :** Project Hoverboard (Polymer SPA), GitHub Pages

### Pages
- Accueil (one-page), Blog, Programme, Orateurs

### Fonctionnalités
- **Hero** : photo panoramique du Capitole, logo
- **Statistiques** : 300 participants, 1 journée, 21 sessions, 3 tracks
- **Speakers** : grille de 7 speakers en vedette avec photo, nom, entreprise ; lien vers page détail
- **Billetterie** : prix unique 30€, lien vers Billetweb
- **Blog** : 2 articles avec aperçu
- **Twitter** : fil intégré #DEVFESTTOULOUSE
- **Réseaux sociaux** : Twitter, Google+, Facebook, LinkedIn
- **Lieu** : Google Maps intégré, IUT Blagnac, bouton itinéraire + site du lieu
- **Partenaires** : 4 niveaux (Platinum, Or, Argent, Médias) + Communautés impliquées (9)
- **Footer** : newsletter (email), contact, liens visiteurs, kit média, proposition de partenariat
- **Code de conduite** : page dédiée

### Absences notables
- Pas de page Équipe (info dans un article de blog)
- Pas de FAQ
- Pas de vidéos replay
- Pas de galerie photos
- Pas de Jobs

## 2017 — https://2017.devfesttoulouse.fr/

**Stack :** Project Hoverboard (Polymer SPA), GitHub Pages

### Pages
- Accueil, Speakers, Programme, Blog, Équipe, FAQ, Jobs (externe Taleez)

### Nouvelles fonctionnalités (vs 2016)
- **Replay vidéos** : bouton "REPLAY VIDEOS" dans le hero, carrousel de 6 vidéos YouTube, lien vers playlist complète
- **Galerie photos** : 3 photos de l'événement, album partagé (contributif) + album officiel (Google Photos)
- **Page Équipe** : grille des organisateurs
- **Page FAQ** : questions fréquentes
- **Jobs** : onglet externe vers Taleez
- **Sign In** : authentification Google (via Firebase)
- **Liste d'attente** : CTA "S'inscrire sur liste d'attente"
- **CFP** : lien vers devfest-toulouse.cfp.io
- **Section organisateur** : présentation du GDG Toulouse

### Évolutions
- 500 participants, 36 sessions, 4 tracks
- Nouveau lieu : Cinéma CGR Blagnac (4 salles)
- Plus de sponsors (5 niveaux + 2 niveaux communautés)
- Contact : contact@devfesttoulouse.fr (nouveau)
- Compte Twitter dédié @DevFestToulouse

## 2018 — https://2018.devfesttoulouse.fr/

**Stack :** Project Hoverboard (Polymer 2 + Redux), Firebase

### Pages
- Accueil, Programme, Speakers, Équipe, Blog, FAQ, Jobs, Code de conduite

### Nouvelles fonctionnalités (vs 2017)
- **PWA complète** : Service Worker, installation, mode offline, push notifications
- **Newsletter Mailchimp** : formulaire intégré (prénom, nom, email)
- **Billetterie à 3 paliers** : BlindBirds (40€), EarlyBirds (60€), Normal (80€) avec état sold-out
- **My Schedule** : planning personnalisé (nécessite authentification), favoris/bookmarks
- **Détails session enrichis** : markdown, slides, vidéo, complexité, langue, durée, tags
- **67 speakers** avec page détail complète (bio, badges, réseaux sociaux, sessions)
- **5 tracks** dont Office Hours (Q&A avec speakers)
- **Carte Google Maps** personnalisée (style custom, marqueur SVG)
- **14 membres d'équipe** affichés en ordre aléatoire

### Évolutions
- 700 participants, 52 sessions (31 conférences + 8 quickies + 8 office hours + 2 keynotes)
- Nouveau lieu : Centre de Congrès Pierre Baudis
- 37 partenaires sur 5 niveaux
- Thème couleur : violet (#673AB7)
- Meta tags sociaux (Open Graph, Twitter Card, Schema.org)

## 2019 — https://2019.devfesttoulouse.fr/

**Stack :** Hugo (site statique), Firebase hosting

### Pages
- Accueil, Schedule, Partners, Sessions, Speakers, Blog, Team, FAQ, Kids, Jobs (sous-domaine)

### Nouvelles fonctionnalités (vs 2018)
- **Site bilingue** : toggle EN/FR (radio button)
- **Section Kids** : programme dédié pour les enfants (/kids/)
- **Jobs sur sous-domaine** : jobs.devfesttoulouse.fr (dédié)
- **Export agenda** : téléchargement ICAL + PDF
- **Vidéo aftermovie** : YouTube intégré dans le hero
- **Galerie photos** : section dédiée avec lien vers Google Photos
- **Pages partenaires individuelles** : chaque partenaire a sa propre page
- **Filtrage sessions** : par catégorie avec tags emoji colorés
- **Office Hours** : colonne dédiée dans le planning

### Évolutions
- 1000 participants, 36 sessions, 4 tracks + Office Hours
- Changement de stack technique : Polymer → Hugo (site statique)
- 8 catégories de talks avec emojis : Web, Languages, WTF, Mobile, Cloud/Infra, Big Data/ML/AI, Méthodes & Outils, IoT
- Salles nommées d'après les sponsors Platinum
- Identité locale : "We love chocolatines" dans le footer
- Liens vers les éditions précédentes (2016-2018)

## 2023-2025 — https://devfesttoulouse.fr/

**Stack :** WordPress (thème Avada), OVH

### Pages
- Accueil, Conférences, Conférencier(e)s, Agenda, Contact, À propos, Éditions passées, FAQ, Code de conduite (FR + EN), Actualités, Mentions légales

### Nouvelles fonctionnalités (vs 2019)
- **CMS WordPress** : administration simplifiée, articles/actualités
- **Filtrage avancé des conférences** : par niveau, format, langue, catégorie, recherche texte
- **Formulaire de contact** : prénom, nom, email, téléphone, objet (dropdown), message
- **Intégration Sessionize** : CFP et gestion du planning
- **Intégration Google Forms** : inscription partenaires
- **Timeline des éditions** : historique interactif au scroll depuis le hero
- **Page À propos** : histoire complète avec frise chronologique
- **Mentions légales** : conformité RGPD
- **Skip to content** : lien d'accessibilité
- **Bluesky** : nouveau réseau social (en plus de Twitter, LinkedIn, YouTube)
- **Page 404 personnalisée** : avec barre de recherche
- **9 catégories de talks** : Applications mobiles, Cloud/Infra/{Dev-Git-Sec}Ops, Developer Experience, IA/ML/Data, Langages, Low code/No code, Méthodes & outils, Tech créative, UX/accessibilité
- **Éditions archivées** : pages dédiées pour 2023, 2024, 2025

### Évolutions
- Nouveau lieu : Centre de Congrès Diagora, Labège
- WordPress remplace Hugo (gestion de contenu par des non-développeurs)
- 70+ conférences, 70+ speakers
- Structure associative formalisée (Association Loi 1901)
- Navigation par dropdowns (Agenda, À propos, Écosystème)
- Écosystème : liens vers Toulouse Tech Hub et Cloud Toulouse
